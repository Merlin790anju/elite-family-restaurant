# Elite Family Restaurant & Bakers — source files

## Open in VS Code
1. Extract this ZIP.
2. In VS Code choose **File → Open Folder** and select `elite-family-restaurant-source`.
3. Edit:
   - `public/index.html` — page text and layout
   - `public/theme.css` — colours, fonts and styling
   - `public/app.js` — menu items and prices

## Preview locally
This site uses Alpine.js and Tailwind from CDNs. The simplest way to preview is with the VS Code **Live Server** extension:
- Open `public/index.html`
- Right-click and choose **Open with Live Server**

Note: this is a local-editing copy of the current restaurant website's frontend. The logo is represented by an `EF` monogram here rather than the original embedded logo image. This ZIP does not include Hatchable's hosting/deployment configuration or backend/database because this app currently uses frontend files only.
